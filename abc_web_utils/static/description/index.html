ABC Web Utils

The shared toolbox behind every free ABC control. No menu, no screen, no feature of its own — just the plumbing the rest of the ABC line reuses instead of reinventing.

Do I need to install this on purpose? Only if Odoo tells you to. It's a dependency: installing any ABC free control that needs it (e.g. ABC Team Stage Filter) pulls it in automatically. On its own it changes nothing — no new menu, no altered behavior, nothing to configure.

What it actually contains

Every ABC control faces the same handful of problems — patch a core component safely, remember a user's preference without polluting other users or databases, parse a pasted Excel range, show a progress bar during a long operation. Instead of every control solving these on its own (and drifting apart release after release), they all lean on this one shared implementation:

  • Safe, reversible patching — additive patch() helpers that always call the original method and can be fully undone, so uninstalling a control never leaves a trace.
  • Per-user, per-database preferences — a small localStorage wrapper namespaced by database, model and user, so one browser used by several people (or several databases) never mixes up saved settings.
  • Excel/Calc paste parsing — turns a clipboard paste into a clean grid of values, with sane size guardrails so a huge accidental paste can't freeze the browser.
  • A progress overlay — one shared, consistent "working…" indicator with percentage and elapsed/estimated time, instead of every control inventing its own spinner.

Why a separate module

Concentrating this plumbing in one place means the fragile points of contact with Odoo's core get updated once each year Odoo releases, instead of once per control. It also means every ABC free hook stays genuinely minimal — a control that adds one feature ships as one small file, not a copy of these helpers bundled in again.

Safe by construction

  • Zero business models, zero data of its own.
  • Installing it changes no existing behavior — it only becomes active through the controls that depend on it.
  • Uninstalling cleans up its own configuration parameters, nothing is left behind.
  • Free and open source (LGPL-3).
